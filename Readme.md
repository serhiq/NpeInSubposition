# Ошибка чтения кода единицы измерения через ReceiptApi.getReceipt()

Это приложение демонстрирует проблему с воспроизведением некорректного чтения кода единицы измерения при работе с `ReceiptApi.getReceipt()` в процессе продажи и после закрытия чека.

## Воспроизведение ошибки

### В процессе продажи

Для воспроизведения ошибки в процессе продажи выполните следующие шаги:

1. Замените `uuid` приложения на ваш уникальный идентификатор.
2. Откройте продажу и добавьте товар, у которого единица измерения указана как литры (`л`).
3. На экране скидок выберите красную иконку в виде чека ("Чек").
4. Обратите внимание, что код единицы измерения будет отображаться как `255`.

### После закрытия чека. OpenSellReceiptCommand.
1. Замените `uuid` приложения на ваш уникальный идентификатор.
2. На рабочем столе откройте приложение `Example`.
3. Нажмите кнопку `start` и распечатайте чек.
4. Обратите внимание, что код единицы измерения также будет отображаться как `255`.
