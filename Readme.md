1. Измените `appId` в манифесте и `MainActivity` для назначения Extra.
2. Установите приложение на терминал.
3. Откройте приложение и нажмите "Start".
4. Наблюдайте за терминалом.

**Результат:**
- Терминал зависает, появляется ошибка: "Ошибка POS".
- При нажатии на продажу отображается зеленый splash screen с калькулятором.
- Через минуту появляется сообщение: "Приложение Pos не отвечает", после чего приложение вылетает.
